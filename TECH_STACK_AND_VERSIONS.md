# ॐ Sri Anvaya — Technology Stack & Versions

## 1. Summary of Technologies
- **Frontend**: Next.js 14 (React 18) + TailwindCSS + TypeScript
- **Backend**: NestJS 10 + Node.js 20 + Express + TypeScript
- **Database**: MongoDB Atlas (Cluster0 Cloud)
- **File Storage**: Multi-Cloud (Cloudinary + AWS S3 + Azure Blob)
- **Payments**: Razorpay (India) & Stripe (International)
- **Deployment**: Netlify (Frontend) + Render (Backend)

## 3. Cloud Services & Hosting Providers
| Service | Provider | Purpose |
|---|---|---|
| **Frontend Hosting** | **Netlify** | Hosts `sriavanya.netlify.app` with global CDN |
| **Backend Hosting** | **Render** | Hosts the Node.js / NestJS API web service |
| **Cloud Database** | **MongoDB Atlas** | Live MongoDB database cluster (`Cluster0`) |
| **Primary Media Storage** | **Cloudinary** | Certified image & certificate signed uploads |
| **Multi-Cloud Storage** | **AWS S3 / Azure Blob** | Built-in secondary document vault options |
| **Domestic Payments** | **Razorpay** | UPI, Cards, NetBanking, recurring subscriptions |
| **Global Payments** | **Stripe** | International credit cards & currency checkout |
