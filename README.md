## 🌟 Key Features

1. **4-Member Dedicated Ritual Team Dispatch Engine**: Allocates 1 Chief Vadhyar, 2 Swamigals (Bhoktas), and 1 orthodox Madi Cook for every Sradham.
2. **Predictable Monthly Subscriptions (Sradham 360)**: Distributes annual ritual expenses into manageable monthly installments with live dynamic pricing across the website.
3. **Multi-Cloud Storage Vault**: Seamless 1-click switching between **Cloudinary Media**, **Amazon AWS S3**, and **Microsoft Azure Blob Storage** with live ping tests.
4. **Subscription Plan Management Hub**: Add, edit, or delete subscription tiers with custom inclusions and live propagation to public catalog and onboarding flow.
5. **Database Disaster Recovery Engine**: 1-click JSON backup export and snapshot import with `OVERWRITE` or `MERGE` modes.
6. **In-App Printable Tax Invoice Engine**: Official Sri Anvaya emblem (`ॐ`), GST compliance, dakshina breakdown, and 1-click PDF print/save.
7. **12% Vedic Provider Welfare Fund**: Automated allocation and month-end welfare reconciliation engine for Vaidika community support.
